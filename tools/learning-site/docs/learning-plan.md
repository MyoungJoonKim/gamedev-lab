# 학습 범위와 핵심노트 검토

여러 장르에 공통으로 쓰이는 게임 기능을 연습하는 과정입니다. 특정 게임이나 프로젝트를 전제로 하지 않습니다. 첨부 문서의 예제를 구현 완료의 증거나 사용자의 숙련도 증거로 간주하지 않습니다.

## 현재 저장소

- 실제 에디터 버전: Unity 2022.3.62f3 (`unity/ProjectSettings/ProjectVersion.txt`).
- Unity MCP v10.0.0 패키지가 manifest에 등록되어 있습니다. 실행 중인 MCP 서버 연결은 확인되지 않았습니다.
- NGO 패키지는 현재 manifest에 없습니다. 네트워크 실습 전 로컬 Unity에서 버전과 설치를 확인해야 합니다.
- 현재 씬은 SampleScene이며 사용자 게임 로직은 아직 없습니다. 웹 코드는 `tools/learning-site/site/`, C# 채점기는 `tools/learning-site/tooling/`에 두어 Unity Assets와 분리했습니다.

## 노트의 핵심

입력은 Owner, 권위 있는 판정은 Host/Server가 수행합니다. 지속 상태는 NetworkVariable/NetworkList, 요청은 RPC, 로컬 UI 반응은 이벤트로 구분합니다. 일반 C# event는 다른 Client로 자동 전송되지 않습니다. NGO의 기존 ServerRpc와 통합 Rpc 문법은 설치 버전에 맞춰 확인합니다.

공통 ScriptableObject 정의와 개별 런타임 상태를 분리하고, 상태 초기 표시와 OnValueChanged 구독·해제를 함께 구현합니다. 단일 아이템에 풀링이나 작은 인벤토리에 Dictionary를 무조건 적용하지 않습니다. NonAlloc도 검색 계산 비용을 없애지는 않습니다. CPU와 GC Alloc을 같은 조건에서 측정한 뒤 구조를 선택합니다.

노트의 프로퍼티 예에서 Hp가 float이면 `int x = player.Hp`는 암시적으로 변환되지 않습니다. 읽는 쪽에 float를 사용하거나 명시적인 반올림 정책을 정해야 합니다. 원본 첨부 문서는 수정하지 않았습니다.

## 단계와 통과 근거

| 단계 | 실습 | 완료 기준 |
|---|---|---|
| 1 C# 흐름 | 포켓 경계값, 고정 슬롯 | 조건·반환값·같은 인스턴스의 상태를 설명하고 실제 테스트 |
| 2 디버거 | 집기 거부 추적 | 중단점·Watch·호출 스택으로 첫 차이 확인 |
| 3 Unity 구조 | Raycast 실패 | 코드·참조·Layer·Collider 설정 문제 구분 |
| 4 이벤트 | UI 중복 갱신 | 재활성화 후 이벤트당 한 번, 현재 값 초기 표시 |
| 5 비동기 | 중복 로딩 | 성공·실패·취소·화면 종료 검증 |
| 6 종합 | 상태와 UI 불일치 | 재현→가설→근거→최소 수정→회귀 검증 |
| 7 Profiler | 자원 탐색 | 동일 씬·대상·빈도에서 CPU ms와 GC Alloc B 비교 |
| 8 NGO | 공유 아이템 동시 획득 | Host+Client에서 동시 요청·권한·늦은 참가 검증 |

회당 25–50분을 기준으로 하되 날짜보다 설명과 재현 가능성을 우선합니다. 사이트의 6문항은 코드 읽기 진단이며 디버거·비동기·Profiler 숙련도를 단정하지 않습니다. Steam·DB·백엔드 저장은 이번 기본 과정 범위 밖입니다.

## 검증과 피드백 구분

기초 12문제는 실제 .NET으로 컴파일하고 테스트합니다. 공개된 유한한 테스트의 통과가 모든 구현의 완전성을 보장하지는 않습니다. Unity 실습의 외부 XML/JSON은 사용자가 제공한 증거이며 대상과 코드 대응을 직접 확인해야 합니다. ‘일부 미실행’과 ‘실패’를 통과로 합치지 않습니다. 코드 변경 후 이전 결과는 재검증이 필요합니다.

문제별 피드백은 학습 가이드입니다. AI 자동 코드 리뷰나 실측 최적화 판정은 현재 구현하지 않았습니다. 검토 제안과 측정 확인을 구분해 기록합니다.

## 하루 기초 3문제

집기 수량 제한, 인벤토리 슬롯, 체력, 연료, 쿨타임, 대상 탐색, 중복 제거, 제작 재료, 요청 대기열, 실행 취소, 내구도, 점수를 기초 문제 은행으로 사용합니다. 전체 19문제 중 자동채점이 가능한 이 12문제에서 하루 3개를 배정합니다.

할당은 한국 시간 기준으로 고정하며 미완료·오래된 문제를 우선하고 모두 풀면 복습합니다. 오늘 할당된 문제의 실제 채점 통과만 달성으로 집계합니다. 같은 문제의 재통과를 중복 집계하지 않습니다. 일일 학습 화면에서 날짜별 할당량과 달력을 확인하고, 학습 기록 삭제와 별도로 완료 이력을 유지합니다.
