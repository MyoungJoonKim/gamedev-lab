# 농장 · 이동 명령 제한 (2026-11-04)

## 문제

학습일: 2026-11-04

농장의 이동 명령 제한 기능을 구현합니다. 오늘의 기준 값은 3입니다. 각 이동 명령을 0 이상 기준 이하로 제한한 배열을 반환하세요.

- 각 이동 명령을 0 이상 기준 이하로 제한한 배열을 반환하세요.
- public int[] Solve(int[] values)를 구현하세요. 결과가 단일 값이어도 길이 1의 배열로 반환합니다.
- null은 빈 배열과 동일하게 처리하고 입력 배열은 변경하지 않습니다.
- 같은 인스턴스에서 여러 번 호출해도 이전 호출의 결과에 영향을 받지 않아야 합니다.
- 입력 길이 0~1000, 각 값 -1000~1000 범위입니다.

## 내 풀이 코드

```csharp
public class DailyPractice
{
    public int[] Solve(int[] values)
    {
        // 기준 값: 3
        // 요구사항을 읽고 직접 구현하세요.
        
        if (values == null)
            return new int[0];
            
        int[] result = new int[values.Length];
        int standard = 3;
        
        if (result == null)
            return new int[0];
            
        for (int i = 0; i < values.Length; i++)
        {
            if (values[i] < 0)
            {
                result[i] = 0;
            }
            else if (values[i] > standard)
            {
                result[i] = standard;
            }
            else
                result[i] = values[i];
        }
        return result;
    }
}

```
