# 농장 · 목표 합 보급쌍 (2026-11-04)

## 문제

학습일: 2026-11-04

농장의 목표 합 보급쌍 기능을 구현합니다. 오늘의 기준 값은 5입니다. 합이 기준인 서로 다른 두 인덱스 [i, j]를 찾으세요(i < j). j가 가장 작고, 동률이면 i가 가장 작은 쌍이며 없으면 [-1, -1]입니다.

- 합이 기준인 서로 다른 두 인덱스 [i, j]를 찾으세요(i < j). j가 가장 작고, 동률이면 i가 가장 작은 쌍이며 없으면 [-1, -1]입니다.
- public int[] Solve(int[] values)를 구현하세요. 결과가 단일 값이어도 길이 1의 배열로 반환합니다.
- null은 빈 배열과 동일하게 처리하고 입력 배열은 변경하지 않습니다.
- 같은 인스턴스에서 여러 번 호출해도 이전 호출의 결과에 영향을 받지 않아야 합니다.
- 입력 길이 0~1000, 각 값 -1000~1000 범위입니다.

## 내 풀이 코드

```csharp
public class DailyPractice
{
    public int[] Solve(int[] values)
    {
        // 기준 값: 5
        // 요구사항을 읽고 직접 구현하세요.
        
        if (values == null)
            return new int[] { -1, -1 };

        const int standard = 5;

        for (int j = 1; j < values.Length; j++)
        {
            for (int i = 0; i < j; i++)
            {
                if (values[i] + values[j] == standard)
                {
                    return new int[] { i, j };
                }
            }
        }

        return new int[] { -1, -1 };
    }
}

```
