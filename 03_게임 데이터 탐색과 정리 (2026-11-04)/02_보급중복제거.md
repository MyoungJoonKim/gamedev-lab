# 농장 · 보급 중복 제거 (2026-11-04)

## 문제

학습일: 2026-11-04

농장의 보급 중복 제거 기능을 구현합니다. 오늘의 기준 값은 4입니다. 0 이상인 ID만 첫 등장 순서대로 한 번씩 반환하세요. 기준 값은 사용하지 않습니다.

- 0 이상인 ID만 첫 등장 순서대로 한 번씩 반환하세요. 기준 값은 사용하지 않습니다.
- public int[] Solve(int[] values)를 구현하세요. 결과가 단일 값이어도 길이 1의 배열로 반환합니다.
- null은 빈 배열과 동일하게 처리하고 입력 배열은 변경하지 않습니다.
- 같은 인스턴스에서 여러 번 호출해도 이전 호출의 결과에 영향을 받지 않아야 합니다.
- 입력 길이 0~1000, 각 값 -1000~1000 범위입니다.

## 내 풀이 코드

```csharp
using System.Collections.Generic;

public class DailyPractice
{
    public int[] Solve(int[] values)
    {
        // 기준 값: 4
        // 요구사항을 읽고 직접 구현하세요.
        
        if (values == null)
            return new int[0];
            
        HashSet<int> temporarySet = new HashSet<int>();
        List<int> result = new List<int>();
        
        for (int i = 0; i < values.Length; i++)
        {
            if (values[i] >= 0)
            {
                if (temporarySet.Add(values[i]))
                    result.Add(values[i]);
            }
        }
        return result.ToArray();
    }
}

```
