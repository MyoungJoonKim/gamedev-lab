# GameDev Lab

여러 게임 장르에 공통으로 쓰이는 기능을 직접 구현하고, 검증하며 쌓아가는 **개인 문제풀이 기록**입니다.

**[문제와 풀이 기록 보기 →](./solutions)**

하루 기초 3문제를 목표로, 문제 이해 → 코드 작성 → 테스트 → 보완 과정을 반복합니다. 학습 기록은 날짜별 커밋으로 정리하고, 같은 날 같은 문제를 다시 풀었다면 마지막 풀이를 남깁니다.

각 기능 폴더의 Markdown에는 **문제와 직접 작성한 풀이 코드**를 담습니다. 아이템·인벤토리·체력·쿨타임·탐색·이벤트·비동기·네트워크 권한 등 특정 게임에 한정되지 않는 개발 역량을 연습합니다.
