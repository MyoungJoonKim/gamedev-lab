# GameDev Lab

게임 개발에 필요한 C#·Unity 기본기를 다지고, **기존 코드를 이해하며 문제의 원인을 찾아 해결하는 능력**을 기르기 위한 개인 학습 저장소입니다. 여러 게임 장르에 공통인 기능을 직접 구현하고 검증하며, 풀이와 개선 과정을 GitHub에 쌓아갑니다.

**[문제와 풀이 기록 보기 →](./solutions)**

## 학습 방식

로컬 학습 사이트를 이용해 **문제 이해 → 구현 → 실행·검증 → 수정 → 기록**의 과정을 반복합니다.

요구사항과 경계 조건을 정리해 코드를 작성하고, 테스트에서 예상과 다른 동작을 추적·수정한 뒤 풀이를 저장합니다. 아이템·인벤토리·체력 같은 기본 기능부터 이벤트·비동기·네트워크 권한까지 학습 범위를 넓혀갑니다.

학습을 꾸준히 이어가기 위해 기초 문제 3개를 하루 목표로 하며, 모두 풀면 복습합니다.

## GitHub 기록

[`solutions/`](./solutions)에 **문제와 직접 작성한 풀이 코드**를 Markdown으로 남깁니다. 폴더는 `01_집기_인벤토리_체력`처럼 순번과 기능명으로 구분하고, 문서에 학습일을 표시합니다.

커밋은 날짜별로 정리하며, 같은 날 같은 문제는 마지막으로 저장한 풀이를 반영합니다. 사이트에서 커밋 내용을 자동 작성한 뒤 검토·수정하여 게시합니다.

- [`unity/`](./unity): Unity 실습 프로젝트
