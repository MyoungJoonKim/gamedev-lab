# 농장 · 구역 최대 부하 (2026-11-03)

## 문제

학습일: 2026-11-03

농장의 구역 최대 부하 기능을 구현합니다. 오늘의 기준 값은 4입니다. 길이가 기준인 연속 구간 중 합이 최대인 구간의 [시작 인덱스, 합]을 반환하세요. 동률이면 앞 구간이며 길이가 부족하면 [-1, 0]입니다.

- 길이가 기준인 연속 구간 중 합이 최대인 구간의 [시작 인덱스, 합]을 반환하세요. 동률이면 앞 구간이며 길이가 부족하면 [-1, 0]입니다.
- public int[] Solve(int[] values)를 구현하세요. 결과가 단일 값이어도 길이 1의 배열로 반환합니다.
- null은 빈 배열과 동일하게 처리하고 입력 배열은 변경하지 않습니다.
- 같은 인스턴스에서 여러 번 호출해도 이전 호출의 결과에 영향을 받지 않아야 합니다.
- 입력 길이 0~1000, 각 값 -1000~1000 범위입니다.

## 내 풀이 코드

```csharp
public class DailyPractice
{
    public int[] Solve(int[] values)
    {
        // 기준 값: 4
        // 요구사항을 읽고 직접 구현하세요.
        
        int indexSize = 4;
        int startIndex = 0;
        int total = 0;
        
        if (values == null || values.Length < indexSize)
            return new int[] {-1, 0};
            
        for (int i = 0; i < indexSize; i++)
        {    
            total += values[i];
        } 
        int max = total;
        
        for (int i = indexSize; i < values.Length; i++)
        {
            total -= values[i - indexSize];
            total += values[i];
            
            if (total > max)
            {
                max = total;
                startIndex = i - indexSize + 1;
            }
        }
        
        return new int[] {startIndex, max};
    }
}

```
