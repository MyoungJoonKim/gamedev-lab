# 농장 · 연속 경보 분석 (2026-11-03)

## 문제

학습일: 2026-11-03

농장의 연속 경보 분석 기능을 구현합니다. 오늘의 기준 값은 3입니다. 기준 이상인 값이 연속해서 나타나는 최대 길이를 반환하세요.

- 기준 이상인 값이 연속해서 나타나는 최대 길이를 반환하세요.
- public int[] Solve(int[] values)를 구현하세요. 결과가 단일 값이어도 길이 1의 배열로 반환합니다.
- null은 빈 배열과 동일하게 처리하고 입력 배열은 변경하지 않습니다.
- 같은 인스턴스에서 여러 번 호출해도 이전 호출의 결과에 영향을 받지 않아야 합니다.
- 입력 길이 0~1000, 각 값 -1000~1000 범위입니다.

## 내 풀이 코드

```csharp
public class DailyPractice
{
    public int[] Solve(int[] values)
    {
        // 기준 값: 3
        // 요구사항을 읽고 직접 구현하세요.
        int _defalt = 3;
        int _current = 0;
        int _longest = 0;
        
        if (values == null)
            return new int[] {_current};
            
        for (int i = 0; i < values.Length; i++)
        {
            if (values[i] >= _defalt)
            {
                _current++;
            }
            else
            {
                _current = 0;
            }
                
            if (_current > _longest)
            {
                _longest = _current;
            }
        }
        return new int[] {_longest};
    }
}

```
