# 아이템 집기와 수량 제한

## 문제

학습일: 2026-11-01

아이템을 획득해 수량을 관리하는 기능을 구현합니다. 예제 자원은 최대 5개까지 보관할 수 있습니다. 같은 포켓에서 집기를 반복해도 한도를 넘지 않도록 만들어 보세요.

- 초기 나무 수량은 4개입니다.
- 성공하면 수량을 1 증가시키고 true를 반환합니다.
- 이미 5개이면 수량을 유지하고 false를 반환합니다.
- WoodCount는 현재 수량을 반환하는 읽기 전용 프로퍼티입니다.

## 내 풀이 코드

```csharp
public class PocketPractice
{
    private int woodCount = 4;
    private const int MaxWoodCount = 5;

    public int WoodCount => woodCount;

    public bool TryPickUpWood()
    {
        // 조건을 확인하고 상태와 반환값을 결정하세요.
        if (woodCount >= MaxWoodCount)
        {
            return false;
        }

        woodCount++;
        
        return true;
    }

    
}

```
